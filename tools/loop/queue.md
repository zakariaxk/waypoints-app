# Loop queue

The orchestrator (`loop.sh`, or a driving agent session) takes the first `open`
row, gives it to an agent, and marks it `[x]` done, `[!]` failed, or `[~]` running
when the agent exits. `[-]` rows are blocked on the owner; the loop skips them.
Agents: do not edit this file; the orchestrator owns it.

Format: `- [ ] L## | REQ-IDS | files it owns | one-line task`

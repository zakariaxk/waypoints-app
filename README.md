# Waypoints

A native iOS social map for the car community: live friends on the map, meets, teams, builds, a mod simulator, and a virtual drag strip. Swift 6 client, Go realtime gateway, Supabase.

The project is being rewritten from scratch. The repository currently holds the plan only:

- [docs/PLAN.md](docs/PLAN.md): product, architecture, wire protocol, design system, every screen, and the work packages.

The previous Expo app and TypeScript WebSocket service are in git history before the cleanup commit.
